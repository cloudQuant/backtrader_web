# 策略评分模型说明

> 适用范围：Backtrader Web 迭代 166 的策略可信度评分。评分仅供量化研究参考，不构成投资建议。

## 1. 输出结构

策略评分输出一个 `0-100` 总分、一个等级，以及 6 个维度的明细解释。

| 等级 | 分数区间 | 含义 |
|------|----------|------|
| S | `>= 85` | 综合表现优秀，但仍需样本外验证 |
| A | `70-84` | 综合表现较好，有继续研究价值 |
| B | `55-69` | 中性偏可用，需要补充验证 |
| C | `40-54` | 风险或稳定性不足 |
| D | `< 40` | 当前结果可信度较低 |

总分公式：

```text
total_score = Σ(dimension_score_i × normalized_weight_i)
```

默认权重会归一化处理，避免配置总和异常导致评分失真。

## 2. 默认维度与权重

| 维度 key | 中文名 | 默认权重 | 主要依据 |
|----------|--------|----------|----------|
| `profitability` | 收益质量 | 20% | 年化收益、Sharpe、Calmar / Sortino 近似指标 |
| `risk_control` | 风险控制 | 20% | 最大回撤、回撤惩罚、风险收益关系 |
| `stability` | 稳定性 | 20% | 胜率、交易样本数、收益稳定性代理指标 |
| `overfitting_risk` | 过拟合风险 | 15% | 已缓存过拟合检测结果；无结果时降级为中位分 |
| `executability` | 可执行性 | 15% | 交易次数、持仓/执行可行性代理指标 |
| `benchmark_comparison` | 基准对比 | 10% | 当前为中性降级维度，后续接入真实 benchmark |

## 3. 降级维度

当某个维度缺少必要数据时，系统会返回：

```json
{
  "degraded": true,
  "score": 50,
  "explanation": "..."
}
```

降级分不是“安全”或“可交易”的结论，只表示当前信息不足。典型场景：

- 过拟合检测结果尚未完成或无缓存
- benchmark 尚未接入
- 回测交易样本太少
- 缺失权益曲线或交易明细

## 4. 过拟合维度接入规则

`overfitting_risk` 会优先读取 `OverfittingService.get_cached_analysis()` 的结果：

- 有真实检测结果：使用 `robustness_score`
- 无检测结果：返回中位分并标记 `degraded=true`
- 多方法检测：以后端聚合后的整体稳健性分数为准

因此推荐流程是：

1. 先运行回测
2. 创建策略评分
3. 启动过拟合检测
4. 检测完成后重新获取评分，让过拟合维度消费真实结果

## 5. 解读边界

策略评分不是交易信号，也不是收益预测。高分只说明当前回测证据在多维度上更完整、更稳健；低分也不代表策略一定亏损。

使用时应同时检查：

- 样本外表现
- Walk-forward 窗口衰减
- Monte Carlo 分布位置
- 交易成本、滑点和容量
- 不同市场状态下的表现

## 6. 后续增强方向

- 引入真实 benchmark 的 Alpha、Beta、信息比和跟踪误差
- 将稳定性从代理指标升级为月度/滚动窗口统计
- 提供保守/均衡/激进三套权重预设
- 用历史策略样本校准维度权重
