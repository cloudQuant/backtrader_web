# 实盘准备与网关

实盘能力以高风险边界设计：配置、连接诊断、实例生命周期和运行状态都应可审计。项目不会因为策略生成或回测完成而自动触发真实交易。

## 准备顺序

1. 在研究工作区完成数据、策略、回测和风险验证。
2. 在交易工作区确认运行单元及风险参数。
3. 由管理员在 **配置 → 网关**管理网关连接和诊断。
4. 检查启动、列表和查询时的实例状态、启动时间、日志及重复 runtime 目录告警。
5. 按组织的审批流程、账户权限和限额执行后续动作。

## 安全要求

- 凭据仅放入 `.env` 或密钥管理服务，不写入策略、截图、知识库或仓库。
- 使用最小权限账户，并限制可交易品种、仓位、单笔和日内风险。
- 先在模拟或隔离环境验证；当网关、数据或风险诊断异常时停止推进。
- 网关原生日志可用于诊断，但对外展示与 API 错误不应泄露数据库或账户敏感信息。

可用网关及其配置随部署环境而变化。请在 `http://localhost:8000/docs` 和管理员页面核对当前能力，而不是依赖固定的券商清单。
