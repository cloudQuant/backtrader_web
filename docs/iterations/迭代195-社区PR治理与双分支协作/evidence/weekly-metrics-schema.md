# 四周治理度量口径（未开始模板）

状态：**未开始。** 以下口径规定后续可复现的收集方法；没有样本或尚未收集时必须填写 `N/A`，
不得推断为零、100% 或治理完成。

## 通用收集规则

- **source system：**GitHub PR、review、check 与 Ruleset 审计记录为主；GitHub/Gitee 的只读
  remote-sync 检查输出用于同步延迟。每个单元格同时记录提取日期、查询范围和保存位置。
- **纳入范围：**收集周内创建、关闭或合并的本仓库 PR/治理事件，具体按各指标分子分母的事件时间
  计算；同一 PR 的重跑不重复计作 PR 总数。
- **排除：**训练、测试、垃圾、重复、管理员明确标记为无效且保留理由的记录；删除的、无法审计的或
  个人敏感评论不进入统计。排除项必须列出数量和理由。
- **数据最小化：**周报只保留 PR 编号/受控证据引用、分支类别、事件时间差和聚合数；不复制私人
  评论、token、邮箱、个人访问令牌或不必要的身份信息。
