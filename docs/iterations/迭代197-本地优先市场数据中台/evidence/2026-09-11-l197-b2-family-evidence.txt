## 已实现的内部机制

- 四个内部 versioned B2 family contract：`futures.inventory`、`option.derivative`、`option.risk_surface`、`crypto.cme_position`；每个 contract 固定 exact dimensions、selector kind 和 type-sensitive semantic record key 派生。
- `20260911_market_data_b2_completeness_evidence` 新增 append-only `md_b2_completeness_receipts` 和 `md_b2_completeness_manifest_entries`，用 `b2_completeness_receipt` publication 控制可见性。
- issuer 从 reviewed dimensions 重新派生 selector、expected semantic-key manifest、zero evidence、manifest digest 与 receipt digest；它在持久化前核对同一 source snapshot、精确 event 的事实 key 集合。
- recovery、直接发布和 strict reader 都重新验证 parent digest、child manifest、zero state 与 exact source-event manifest；source receipt 与 B2 receipt 必须同时位于同一 frozen visibility anchor。
- strict reader 将请求 selector 限为 receipt lookup coordinate；只从 durable receipt 重建 selector/manifest/zero certificate，只查询 receipt-bound source snapshot。证据缺失返回 `DURABLE_SELECTOR_EVIDENCE_MISSING`，不读取事实或返回 partial；cursor 还绑定 receipt ID/hash 和 source snapshot ID。
- 全部 B2 family 仍保持 `DATA_FAMILY_UNCONFIGURED`。本实现没有 public route、provider adapter、AkShare/OpenBB 调用、scheduler、capability permit 或前端入口。
