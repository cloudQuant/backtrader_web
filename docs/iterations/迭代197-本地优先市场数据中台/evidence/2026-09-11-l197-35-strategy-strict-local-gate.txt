Changed scope
-------------
- The Strategy page forces a fresh capability decision before new research,
  run-record continuation, and task-snapshot continuation.
- With an effective bridge it issues an exact frozen-submission
  local_only/research/strict precheck and permits only strict_local coverage.
- Contract errors, v2 fallback, query errors, incomplete coverage, response
  mismatch, aborted precheck, and known-enabled capability-read failure stop
  the action before its submit/continue API.
- The backend applies a durable bridge preflight to sync run, async task
  submit, task continuation, and run continuation. An effective bridge
  rejects a request without binding intent before mandate validation, task
  materialization, snapshots, research execution, or artifact binding.
- If either operator kill switch is disabled, the legacy route remains
  unchanged and does not open a capability-ledger session or require data:read.
