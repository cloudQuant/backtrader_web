## 6. 风险评估

| 风险 | 影响 | 缓解 |
|------|------|------|
| Airflow 模块拆分 commit 时引入隐式依赖 | 中 | 每个 commit 单独 `git checkout` 验证后端启动 + smoke test |
| `audit_service` 异步 sink 反压拖慢主请求 | 高 | T3 明确"写失败不影响主请求"，加 bounded queue + drop 策略 |
| AI 交易语义变更（T7）破坏前端 UI | 中 | 在 `api/ai_trading.py` 增加 `degraded` 字段而非改 schema；前端兜底渲染 |
| mypy 棘轮被绕过（# type: ignore） | 低 | CI 同时跑 `--strict-equality` + 禁用未使用 ignore（`warn_unused_ignores` 已开） |
| B904 局部修改产生大量代码改动 | 中 | 仅 scope `api/`，预计 50-100 处；按文件 PR |
| 移除已 tracked 的 coverage/db 文件影响他人本地 | 低 | 通知后再 `git rm --cached`；提供 `git clean` 一次性命令 |
