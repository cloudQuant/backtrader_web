# 迭代129 - 增加知识库和 AI 问答 - 前端组件设计

> **文档状态**: 已优化，作为开发基线
> **最后更新**: 2026-04-23

---

## 1. 设计目标

在不破坏 backtrader_web 现有布局和编码风格的前提下，为知识库与 AI问答提供可扩展的页面、组件、store 与 API 封装。

原则：

1. 继续采用 Vue 3 + TypeScript + Element Plus + Pinia；
2. 继续复用 `src/frontend/src/components/common/AppLayout.vue`；
3. 继续复用 `src/frontend/src/api/index.ts` 作为统一 API 客户端；
4. 所有 ID 类型统一为 `string`；
5. P0 优先保证主流程，P1 能力作为扩展面板或独立页面。

---

## 2. 路由设计

### 2.1 新增路由

建议在 `src/frontend/src/router/index.ts` 中增加以下子路由：

```ts
{
  path: 'ai-chat',
  name: 'AIChat',
  component: () => import('@/views/AIChatPage.vue'),
},
{
  path: 'knowledge-base',
  name: 'KnowledgeBase',
  component: () => import('@/views/KnowledgeBasePage.vue'),
},
{
  path: 'knowledge-base/:id',
  name: 'KnowledgeBaseDetail',
  component: () => import('@/views/KnowledgeBasePage.vue'),
},
{
  path: 'ai-assistant',
  name: 'AIAssistant',
  component: () => import('@/views/AIAssistantPage.vue'),
},
```

### 2.2 菜单接入

需要同步修改 `AppLayout.vue`：

1. 菜单项新增：
   - `/ai-chat`
   - `/knowledge-base`
2. 菜单顺序更新为：

```text
首页 -> AI问答 -> 数据管理 -> 行情报价 -> 策略研究 -> 策略交易
-> 策略管理 -> 组合管理 -> 账户管理 -> 知识库 -> 系统设置
```

3. `currentRoute` 的 prefix 列表要加入：
   - `/ai-chat`
   - `/knowledge-base`
   - `/ai-assistant`（如果本期上线）
4. `pageTitle` 映射要增加：
   - `/ai-chat`: `AI问答`
   - `/knowledge-base`: `知识库`
   - `/ai-assistant`: `AI助手`

## 6. API 封装设计

### 6.1 基线约束

现有项目 API 基类为：

```ts
import api from './index'
```

因此新增封装应遵循现有模式，不使用文档草稿中错误的 `@/utils/request` 路径。

### 6.2 建议文件

```text
src/frontend/src/api/
├── knowledgeBase.ts
├── kbChat.ts
├── rag.ts
└── aiAssistant.ts
```

### 6.3 knowledgeBase.ts 示例

```ts
import api from './index'

export const knowledgeBaseApi = {
  list(params?: { skip?: number; limit?: number; search?: string }) {
    return api.get('/knowledge-base/', { params })
  },
  get(id: string) {
    return api.get(`/knowledge-base/${id}`)
  },
  create(data: { name: string; description?: string; is_public?: boolean }) {
    return api.post('/knowledge-base/', data)
  },
  update(id: string, data: { name?: string; description?: string; is_public?: boolean }) {
    return api.put(`/knowledge-base/${id}`, data)
  },
  remove(id: string) {
    return api.delete(`/knowledge-base/${id}`)
  },
}
```

### 6.4 kbChat.ts 示例

```ts
import api from './index'

export const kbChatApi = {
  listConversations(params: { knowledge_base_id: string; skip?: number; limit?: number }) {
    return api.get('/kb-chat/conversations', { params })
  },
  createConversation(data: { knowledge_base_id: string; title?: string; model_id?: string }) {
    return api.post('/kb-chat/conversations', data)
  },
  getHistory(conversationId: string) {
    return api.get(`/kb-chat/history/${conversationId}`)
  },
  send(data: {
    knowledge_base_id: string
    conversation_id?: string | null
    question: string
    model_id?: string
    thinking_mode?: boolean
  }) {
    return api.post('/kb-chat/send', data)
  },
}
```

## 7. 关键交互说明

### 7.1 知识库页关键交互

1. 创建知识库后自动选中并跳转到详情态；
2. 左侧知识库切换时刷新文档树与 AI 问答上下文；
3. 导入文档后刷新文档列表并提示索引状态；
4. 删除知识库前二次确认。

### 7.2 AI 问答页关键交互

1. 未选择知识库时禁止发送问题；
2. 新建对话后自动成为当前会话；
3. 消息发送期间输入区禁用并展示 loading；
4. 回答返回后展示引用来源；
5. 历史对话切换时恢复上下文。

## 8. P0 / P1 视觉与交互边界

### P0

1. 先保证布局完整与主流程可用；
2. 暂不追求复杂拖拽、虚拟滚动、流式思维链展示；
3. 问答支持同步返回即可；
4. 文档导入先保证基础格式。

### P1

1. 增加更复杂的文档树交互；
2. 增加模型筛选与高级参数；
3. 增加 AI 助手独立面板；
4. 增加更强的引用展示与 reasoning 面板。
