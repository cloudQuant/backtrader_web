# 迭代129 - 增加知识库和 AI 问答 - 业务验收测试用例清单

> **文档状态**: 已优化，作为验收基线
> **最后更新**: 2026-04-23

---

## 1. 测试目标

本清单用于验证本迭代 P0 闭环是否成立：

1. 菜单入口位置正确；
2. 知识库管理可用；
3. 文档管理可用；
4. 文档可被索引；
5. AI 问答可基于知识库返回答案与引用；
6. 鉴权与权限行为正确。

## 10. 验收标准汇总

### 10.1 功能验收标准

| 模块 | 验收标准 |
|------|----------|
| 菜单接入 | 两个入口位置正确，跳转正确 |
| 知识库 | CRUD 可用，列表与详情一致 |
| 文档 | CRUD 可用，树结构正确，基础导入可用 |
| 索引 | 至少支持单文档索引与失败提示 |
| AI问答 | 能基于知识库返回答案与引用 |
| 权限 | 未登录和非 owner 场景受控 |

### 10.2 性能建议指标

| 指标 | 建议目标 |
|------|----------|
| 页面初次打开 | < 2 秒 |
| 单次问答响应 | < 5 秒（不含大模型极端波动） |
| Markdown/TXT 导入 | < 10 秒/文档 |
| 单文档索引 | 可接受的同步等待或明确异步提示 |

### 10.3 文档验收标准

交付时文档本身也应满足：

1. 菜单位置、路径、接口、ID 类型一致；
2. P0/P1 边界明确；
3. 可直接指导开发拆任务；
4. 与实际实现出现偏差时已完成回填更新。
