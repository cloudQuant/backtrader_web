## 三、中期发展方向（3-12 个月）

### 3.1 AI-Native 深化

```text
当前状态 ──────────────────────────────────────→ 目标状态

AI Copilot（问答/生成）                         AI 策略工厂
├── 单次对话生成                                ├── 批量生成 + 自动评估
├── 人工判断质量                                ├── AI 评分 + 过拟合检测
├── 手动回测验证                                ├── 自动回测管道
└── 手动部署                                    └── 渐进式自动部署
```

### 3.2 平台化准备

| 能力 | 当前 | 目标 | 关键技术 |
|------|------|------|----------|
| 用户系统 | 单用户 JWT | 多租户 RBAC | Casbin + Schema 隔离 |
| 策略共享 | 无 | 策略市场 MVP | 审核流程 + 跟单引擎 |
| 插件系统 | 无 | 数据源插件 SDK | Python 插件接口规范 |
| 部署方式 | Docker Compose | K8s Helm Chart | Helm 3 + HPA |

### 3.3 商业化验证

| 里程碑 | 时间 | 验证假设 |
|--------|------|----------|
| Pro 版本上线 | +3 个月 | 用户愿意为 AI 功能付费 |
| 首批 50 付费用户 | +6 个月 | 定价合理、价值感知足够 |
| 企业版试用 | +9 个月 | 团队用户有强付费意愿 |
| 月收入 ¥15,000 | +12 个月 | 商业模式可持续 |
